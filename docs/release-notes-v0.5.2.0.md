# v0.5.2.0 — 授權收斂 · 效果宣告化 · 外部閘門 🔒🧹🪟

**自 v0.5.1.0 以來 25 個 merge、149 個 commit。** 這版的主題是**把授權收到三個模式、把工具的效果從寫死的特例改成設定裡的宣告、把外部文字關在牆外**。Loom 已經有一個能自己判斷「這件事要不要問人」的分類器（#690），也有能查記憶、能自己動手的工具；缺的是**每一層只留一個決定點**、**每一個工具的效果都說得出來**。於是這版把散在程式裡的特例搬進設定、把過寬的放行收窄、把不該由外部文字決定的事擋下來。

## 重點

### 🔒 權限模式收斂為 安全／自理／YOLO（#704）

- **單一模式**：權限只剩 安全／自理／YOLO，預設自理（#705）。
- **單一決定點**：所有受管制的呼叫走同一個決定點；`/auto` 與「工具名就算授權」退役；自理的未知操作交給 Luna 判斷（#707）。
- **人工確認只剩「允許這次」**：按下去不留任何 grant、lease 或 auto；每批暫停的 HITL 與 penalty box 退役；連續三次拒絕以 `operator_denials` 結束這一回合（#709）。
- **自理可以委託**：自理的委託開 issue、委託發文不經 shell，也把 Luna 的行為量測下來（#706）。
- **先讀後寫回到契約**：新建檔案不用先讀；覆寫要在本 session 讀過、而且之後沒被改過（比對 sha256），真正寫入那一刻再檢查一次；守門原因統一成一行「守門・<層>：<原因>」，CLI 與 Discord 同一格式，模式常駐顯示（#711）。

### 🤖 自動核准分類器：先規則、再模型（#690）

- 分類器本體落地：規則先判，模型只處理規則沒蓋到的（#698）。
- 唯讀規則放寬、唯讀 shell 不再問 DK、確認畫面看得到分類器的判斷與模式（#703、#699）。
- 工具名永遠不授權 shell（#695）；失敗的呼叫有一致的 `[tool_failure]` 契約（#696）。
- ledger 每個回傳路徑都寫 END、runtime 帶 turn origin 與 fired_at、取消與例外也收尾（#691、#692）。
- autonomy 端：權限名稱會對照工具表檢查、每次 trigger 觸發都留檔、評估器對齊分鐘邊界（#693、#694、#697）。
- DK 手工同意過的技能檢查模組會被記住，不必每次重問（#701）。

### 🧹 技能與排程收斂（#708 S1–S2b）

- **喵吉直切**：家具指向技能，`SKILL.md` 的 allows 就是喚醒邊界（#714）。
- 節律與排程改為引用技能邊界，硬護欄原樣保留（#715）。
- 七項 legacy 活動完成盤點，附 S2b 遷移片段（#716）。

### 🌦️ 天氣、窗戶與外部文字護欄（#708 S3）

- **共用天氣**：原生 `weather` 工具與窗戶家具共用同一份查詢；query 與 peek 都不寫快取、不寫生活狀態，回應有大小上限與整體 deadline（#717）。
- **窗戶只講結構化的事**：「開始下雨」「降溫 3°C」由程式從驗證過的欄位產生，外部自由文字與錯誤內容不會進到訊號裡。
- **外部文字被關在牆外**：外部來源的喚醒只留下第一方唯讀工具與一條有界的 append-only 日誌；缺金鑰、policy 缺席或查核例外一律 fail closed；子代理拿不到這道閘門的工具。

### 🔌 MCP 效果宣告化、Plugin／Adapter 退役（#708 S4a–S4b）

- **Python Plugin／Adapter 退役**：`@loom.tool`、`LoomPlugin`、`~/.loom/plugins` 的自動掃描全部移除，MCP 成為唯一的外部擴充通道（#718）。
- **MCP 工具效果改為宣告**：`loom.toml` 的 `[[mcp.servers]]` 用 `tool_effects` 宣告（封閉詞彙 `public_search`／`media_read`、per-server 隔離、遠端 annotations 永不採信、未宣告一律 fail closed、描述命中 mutating 關鍵字則拒絕降級）（#718）。
- **載入期就說清楚**：排程與節律表把技能名寫成工具名、殘留已退役的 MCP 名稱，啟動時就印 WARNING；刻意保留的 legacy 訊息降為 INFO，真正的漏遷移仍是 WARNING（#719）。
- **新聞容量有解**：寫入收窄到 `news/current`，新增只搬不刪的安全歸檔腳本（固定父目錄 fd、原子 no-replace rename）（#719）。

### 🤝 OpenCode Go 訂閱閘道（#712）

- 新增 `opencode-go` provider：OpenAI 相容、只從 `OPENCODE_API_KEY` 認證、每個請求帶穩定的 `x-opencode-session`、輸出遮罩並有大小上限與 5 秒 deadline。
- `loom.toml` 可以選它當主模型、當額度備援，或指定給自動核准分類器（`review_model`）；未設定時行為完全不變。

### 🧰 開發者與工具鏈

- 新開的 worktree 自動連結主樹的本地脈絡與共用的 Claude memory（#710）。
- `_archive/648-…` 移出版本控制（#713）。

### ✅ 測試

全套在乾淨 checkout 上是綠的（**5252 passed / 4 skipped**）。這版新增的守門都有紅燈先行：先讀後寫的契約、外部文字護欄、plugin／adapter 退役、MCP 宣告式效果、載入期漂移偵測。

## 升級說明

- **`loom.toml` 還留著 `[plugins]`／`[adapter]`／`[adapters]`**：這些段已退役，會印一行 WARNING 並被忽略，可以直接刪掉（#718）。
- **MCP 工具要在對應的 `[[mcp.servers]]` 補 `tool_effects`**：沒有宣告的 MCP 工具一律 fail closed；排程與 chime 裡的搜尋會直接被跳過，日常看圖也會退回審查。這一步建議與升級同步做（#718）。
- **房間（room）家具要標 `input_trust = "local"`**：省略時預設 external，該家具的 exec／write 會被移除；喵吉那一筆必須先標好，否則喚醒時她無法照顧喵吉（#717）。
- **`news` 技能改寫到 `news/current`**：歷史新聞不會被刪，歸檔腳本只負責把舊日期搬走（#719）。
- **排程與節律表若把技能名寫成工具名**，載入期會印 WARNING 指出該改用 `skills = [...]` 或 `load_skill`（#719）。
- **既有資料未受影響**：session、記憶與 ledger 的內容都不變；`review_model` 未設時仍是 `codex/gpt-6-luna`。
